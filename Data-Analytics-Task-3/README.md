# Superstore Deep-Dive Analysis & Interactive Dashboard

## Project Overview

This project analyzes the Superstore dataset to identify key business insights and build an interactive dashboard.

## Objectives

- Perform deep-dive business analysis
- Calculate KPIs
- Generate visualizations
- Build an interactive dashboard
- Present business insights

## Technologies Used

- Python
- Pandas
- Matplotlib
- Plotly
- Streamlit
- OpenPyXL

## 📊 Key Performance Indicators

| KPI | Description |
|------|-------------|
| 💰 Total Sales | Total revenue generated from all orders |
| 📈 Total Profit | Overall profit earned |
| 🛒 Total Orders | Number of customer orders |
| 💳 Average Order Value | Average revenue per order |
| 📊 Profit Margin | Profitability percentage |

## 📈 Business Analysis

| Analysis | Description |
|----------|-------------|
| 🌍 Sales by Region | Compared sales performance across geographical regions |
| 📦 Sales by Category | Evaluated category-wise revenue and profitability |
| 👥 Sales by Segment | Analyzed customer segment performance |
| 📅 Monthly Sales Trend | Examined monthly revenue trends |
| 🏆 Top Customers | Identified highest-value customers |
| 📦 Top Products | Ranked products by sales performance |
| 🎯 Customer Segmentation | Studied purchasing behavior across customer groups |
| 💰 Profit by Sub-Category | Compared profitability across product sub-categories |

## 🚀 How to Run

### 1️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 2️⃣ Run the Analysis

```bash
python main.py
```

### 3️⃣ Launch the Streamlit Dashboard

```bash
streamlit run Dashboard/app.py
```
